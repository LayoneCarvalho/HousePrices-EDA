# House Prices – Exploratory Data Analysis

## About the Project

This project is part of my Data Analytics coursework. The goal was to explore the House Prices dataset from Kaggle and understand how different house characteristics relate to sale prices.

## Dataset

The dataset contains 1,460 houses and 81 columns, including information about house size, quality, garage capacity, and sale price.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

I explored the dataset by checking missing values, duplicates, and summary statistics. I also created graphs to understand house price distribution and relationships between variables.

## Key Findings

- Most houses are concentrated in the lower and middle price ranges.
- Larger houses generally have higher sale prices.
- House quality appears to be strongly related to sale price.
- Some properties have unusually high prices.
